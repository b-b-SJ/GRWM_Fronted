 모두잉 (Moduing)

> 함께 계획하고, 기록하고, 협업하는 올인원 플래너 & 커뮤니티 서비스

기존의 개인 플래너 서비스를 넘어, 같은 목표를 가진 사용자들이 함께 계획을 세우고 진행 상황을 공유하며 동기부여를 받을 수 있는 협업 플랫폼입니다.

개인 및 공유 플래너, 트래커, 실시간 채팅, 협업 공간, 커뮤니티 기능을 하나의 서비스에서 제공합니다.

---

## 프로젝트 기간

- 2025.03 ~ 2025.11

---

## 담당 역할 (Frontend)

프로젝트에서 Frontend 개발을 담당했으며, 실시간 협업 기능 구현을 중심으로 개발을 진행했습니다.

### 담당 기능

- React 기반 사용자 인터페이스(UI) 구현
- WebSocket을 활용한 실시간 채팅 기능 구현
- 협업 공간(Workspace) 화면 및 기능 개발
- Planner 및 Tracker 기능 개발 지원
- Backend API 연동 및 화면 데이터 처리
